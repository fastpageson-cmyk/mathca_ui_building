# Developer Handoff Notes

이 파일은 기능 개선 시안을 개발팀에 전달할 때 필요한 결정사항을 모아두는 문서입니다. 새 개선 시안을 만들 때마다 아래에 항목을 추가합니다.

## Survey Complete Intro Message

상태: 시안 생성됨

관련 시안:

- `mockups/survey-complete-intro.html`
- `index.html`의 `설문 완료 개선안` 토글

요청 기능:

- 설문 완료 페이지에 `상대에게 전해줄 자기소개 한마디` 입력란을 추가합니다.
- 입력된 내용은 매칭 결과 이메일에서 상대 이메일 아래에 노출되는 소개 문구 영역에 사용합니다.
- 사용자가 입력하지 않으면 현재 이메일에 들어가는 기본 문구를 그대로 사용합니다.

정책:

- 필수 여부: 선택 입력
- 최대 글자 수: 100자
- 안내 문구: `매칭된 상대에게 처음 전달된 한마디를 적어주세요.`
- 수정 가능 시점: 언제든지 수정 가능
- 빈 값 처리: 기존 이메일 기본 소개 문구 유지

개발팀 확인 필요:

- 이 값을 저장할 필드명과 저장 위치
- 이메일 템플릿에서 해당 문구가 들어갈 정확한 위치
- 사용자가 수정한 값이 이미 예약된 이메일 발송 전에 반영되는 기준 시점
- 부적절한 표현 필터링 또는 신고 정책 필요 여부
